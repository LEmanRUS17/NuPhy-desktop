# Air75 Config

Десктопное приложение для настройки клавиатур на QMK/VIA в стиле nuphy.io. Интерфейс на русском и английском.

- `dist/Air75 Config 0.1.0.exe` — портативная версия, установка не нужна.
- `npm start` — запуск из исходников.
- `npm run demo` — без клавиатуры (демо NuPhy Air75 V2); `electron . --demo=via` — демо KBD75 из базы VIA;
  `electron . --demo=unknown` — клавиатура без описания.
- `npm test` — проверка разбора описаний клавиатур.
- `npm run dist` — пересобрать .exe.

## Какие клавиатуры поддерживаются

Описание клавиатуры (матрица, расположение клавиш, собственные коды) берётся по порядку:

1. **Встроенные** — NuPhy Air60 / Air75 / Air96 V2 и Halo65 / Halo75 / Halo96 V2
   (`src/boards.js`, генерируется `node tools/gen-boards.js` из `ref/*.json` — исходников nuphy-src/qmk_firmware).
2. **Сохранённые** — ранее скачанные или загруженные вручную (хранятся в профиле приложения).
3. **База VIA** — `usevia.app/definitions` по VID/PID; нужен интернет при первом подключении.
4. **Вручную** — если ничего не нашлось, приложение попросит JSON: формат VIA (с вкладки Design),
   описание из базы VIA или `keyboard.json` / `info.json` из QMK. Кнопка «Описание» в верхней панели
   позволяет заменить описание для подключённой клавиатуры.

Клавиатура подключается **кабелем**. Изменения клавиш пишутся в клавиатуру сразу.

## Устройство

- `src/via.js` — протокол VIA по WebHID (раскладка, макросы, подсветка, матрица нажатий, варианты раскладки);
- `src/definitions.js` — поиск и разбор описаний (KLE, база VIA, QMK);
- `src/keycodes.js` — коды QMK; собственные коды клавиатуры подставляются из описания;
- `src/i18n.js` — строки интерфейса RU / EN.
